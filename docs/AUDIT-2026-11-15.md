# Feature audit: LMS + Studio (2026-11-15)

**Checked:** code on `main` (42bb9b2), live database (read-only), Supabase security advisor. `npm test`, `npm run lint` and `npm audit` all pass with 0 problems.
**Live numbers:** 8 students, 2 with course access, 1 Razorpay purchase, 37 leads, 3 schools, 0 teachers, 3 lesson-progress rows, 4 quiz attempts.

**Required** = needed for paying students to get what they paid for, or to sell. **Nice** = useful but can wait. **Cut/park** = not needed at this size.

## Security / logic flaws (ranked)
1. **Paid videos can be shared** (unsigned Bunny embed). Fix: turn on Bunny token authentication plus signed embed links per student (code side ~1 PR, needs the Bunny token key in Vercel).
2. **Certificates not built**, but promised in the course. Due before Batch 1 ends.
3. **No reminders** (Automations empty). Email first: "module opens Sunday" plus "inactive 7 days".
4. **Leaked-password protection off**: one toggle in Supabase → Auth → Passwords.
5. Advisor warning "71 security-definer functions callable by signed-in users": **by design**, every `admin_*` function checks `is_admin()` and the tests cover it. No action.
6. "RLS on but no policy" on 5 tables (trash, OTP, signup limits, consent codes, studio_admins): **intended**, only server code reads them.
7. Deleting a student has no undo.
